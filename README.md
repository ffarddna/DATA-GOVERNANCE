# DATA-GOVERNANCE
📁 Lab 1 – Data Governance Fundamentals & Data Quality Profiling

Description
Learned the basics of data governance by generating a sample customer dataset with data quality issues. Used Python to profile the dataset, identify missing values and invalid records, analyze data statistics, and create a metadata dictionary for better data management.

Technologies Used

Python
Pandas
NumPy
Jupyter Notebook
ydata-profiling

Key Learning Outcomes

Generated sample datasets
Performed data profiling
Identified missing and invalid data
Created a metadata dictionary
Learned data governance concepts
📁 Lab 2 – Data Classification & Automated Quality Enforcement

Description
Applied data governance techniques by classifying data based on sensitivity, masking personal information, and validating records using business rules. Invalid records were separated into a quarantine dataset while valid records were kept for production use.

Technologies Used

Python
Pandas
Jupyter Notebook

Key Learning Outcomes

Classified sensitive data
Applied data masking
Built validation rules
Automated data quality checks
Separated valid and invalid records
Applied PDPA and GDPR concepts
📁 Lab 3 – Data Profiling & Missing Values

Description
Explored the Titanic dataset to assess data quality and handle missing values. Used different cleaning methods such as removing incomplete rows, filling missing values with the median, and dropping columns with excessive missing data.

Technologies Used

Python
Pandas
Google Colab

Key Learning Outcomes

Explored real-world datasets
Detected missing values
Applied data cleaning techniques
Performed median imputation
Prepared data for analysis
📁 Lab 4 – Data Quality Assessment: Duplicates, Outliers & Inconsistencies

Technologies Used

Python

Key Learning Outcomes

Removed duplicate records
